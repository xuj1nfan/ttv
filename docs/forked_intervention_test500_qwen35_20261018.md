# Qwen3.5-9B：CAIL2018 500 案 A/B 过程反馈实验

运行日期：2026-10-18。使用既有过滤后的 500 案测试集；本轮不抽样、不调阈值。该测试集此前已用于 Qwen3-8B 的 500 案实验，因此这里是按用户要求进行的跨模型复跑，不能视为从未查看过的全新测试集。

## 固定条件

- 生成模型服务 ID：`Qwen3.5-9B`；服务端模型目录：`/data/xujinfan/models/qwen3.5-9b`。
- 与上一轮一致的案件、标签词表、提示词、模型采样设置、JSON Schema enum 和 NLI 模型；本轮配置只改了 generator model ID。NLI 为原有本地 XLM-R-large-XNLI 权重，不训练或改权重。
- A/B 每案均从同一个保存的显式分析 checkpoint 与同一条命题分叉；A 不接收验证反馈，B 根据 NLI 结果和固定阈值反馈。Chat API 不能恢复模型内部隐藏状态，本实验只保证外部消息前缀一致。
- 操作阈值：Conflict 0.80，Insufficient 0.85。它们是预设阈值，不代表概率校准。
- 测试数据 SHA-256：`712200c6f83fb271cee4874e4c8532ff39ec8de2b6cf979a3d8b311bc1dd1f4e`。

## 结果

| 指标 | A：Qwen only | B：Qwen + NLI |
|---|---:|---:|
| 案件数 | 500 | 500 |
| 准确数 / 准确率 | 353/500（70.6%） | 353/500（70.6%） |
| 非法/无效输出 | 0 | 0 |
| 反馈触发 | 0 | 87 |

配对 A→B 转移：纠错（错→对）2 例；有害干预（对→错）2 例；两组都对 351 例；两组都错 145 例。净准确率变化 **+0.0 个百分点**；配对 bootstrap 95% 区间为 [-0.8, +0.8] 个百分点（1000 次重采样）。

NLI 对 500 条命题均给出了类别判断：Support 371、Insufficient 123、Conflict 6；达到阈值并实际发送反馈 87 次（Insufficient 85、Conflict 2）。触发后最终罪名发生变化 6 次：2 次纠错、2 次对→错、2 次仍然错误但改成另一个罪名；其余 81 次未改变最终罪名。不能把 87 次反馈触发称为 87 次成功纠错。

## 对研究问题的回答

1. **加入 NLI 反馈未观察到总体准确率提升**：A 与 B 均为 70.6%，配对净变化为 0；目前结果不足以支持 NLI 反馈提高了最终预测准确率。
2. **观察到有害干预 2 次**：A 原本正确而 B 变错，占全部 500 案的 0.4%，占 A 正确案的 0.57%。两例均发生在触发反馈的案件中。
3. **Oracle 组未运行**：运行快照中没有可用的人工确认命题标签。不得以模型生成标签替代人工标注，因此本轮不报告 Oracle 潜在收益。

### 三种效应的区分

- **Verification Quality（局部命题验证质量）**：本轮没有独立人工核验的命题标签，无法计算 XLM-R 的局部验证准确率、召回率或校准质量。概率与类别已逐案保存，但不能据此宣称验证器可靠。
- **Intervention Effect（干预效应）**：在同一外部 checkpoint 配对设计下，观测准确率净变化为 0，纠错和有害干预各 2 例。
- **Feedback Utilization（反馈利用）**：87 次反馈中 6 次最终罪名改变（6.9%）；仅 2 次改变为正确预测，另 2 次由正确变错，2 次仍错。反馈是否“被遵循”不等于反馈是否正确或有益。
